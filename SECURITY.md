# Política de segurança

Este repositório guarda só a documentação do servidor MCP do **cloo.be - Clube de Ofertas**. O servidor roda em `https://cloo.be/mcp`, e o código dele não fica aqui.

## Versões cobertas

| Versão | Coberta |
|--------|---------|
| Servidor em `https://cloo.be/mcp` (versão atual no registro oficial: `be.cloo/ofertas`) | Sim |
| Versões anteriores | Não: o servidor é único e sempre atualizado |

## Como relatar uma vulnerabilidade

**Não abra issue pública** para falha de segurança.

1. Use o relato privado do GitHub: aba **Security** deste repositório, botão **Report a vulnerability**.
2. Ou escreva para **contato@cloo.be** com o assunto `Segurança`.

Inclua, se puder:
- a ferramenta ou o endereço afetado (por exemplo `buscar_ofertas`, `/mcp`, `/ir/`);
- os passos para reproduzir e o que acontece;
- o impacto que você vê (dados expostos, link de compra adulterado, indisponibilidade).

## O que esperar

- Resposta inicial em até **3 dias úteis**.
- Avaliação e plano de correção em até **10 dias úteis**.
- Aviso quando a correção estiver no ar. Se quiser, damos o crédito no relato.

## Fora do escopo

- Preço ou estoque diferente na loja: o preço vem das APIs oficiais das lojas e pode mudar entre a consulta e a compra. Isso não é falha de segurança.
- Problemas nos sites das lojas parceiras: relate direto a elas.
- Testes que derrubam o serviço (carga, negação de serviço) ou que usam dados de outras pessoas.

---

## Security policy (English)

This repository holds documentation only. The server runs at `https://cloo.be/mcp`; only the current version is supported.

Please **do not open public issues** for security problems. Report privately via **Security → Report a vulnerability** on this repository, or email **contato@cloo.be** with the subject `Security`. We reply within 3 business days.
